# RideNite demo (SIMULATED DEMO, sample data)

Static, offline, clickable walkthroughs. No build step, no backend, no real payments, rides or POS connections. Example venue: Maison Cheryl (2900 Wilson Blvd, Arlington, VA), shown as an illustrative example; not a live RideNite partner. Menu item names are from its published menu; prices, guests, drivers, rides, car services and the second venue (Bar Lumen) are sample data.

- `/` – index page linking both demos
- `/pos-demo/` – POS integration walkthrough
- `/prototype/` – UI prototype

Deployed as a DigitalOcean App Platform static site (see `.do/app.yaml`).
